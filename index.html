Things I've built

RateMyProfessor Analyzer
data + AI
I reverse-engineered RateMyProfessor's internal GraphQL API so you can search any professor by name and school and get their ratings, difficulty scores, and up to 100 reviews, no URL needed. It charts the data with Pandas and Seaborn, then feeds the reviews into Groq's LLaMA 3.3 70B to write a plain-language summary of what students actually think.

Fossil Age Regression
ML
I trained four regression models to predict a fossil's geological age from taxonomic and geospatial features like species, rock type, and location. After benchmarking Lasso, XGBoost, and two neural networks, I tuned XGBoost with cross-validated random search and cut the RMSE by 90%, landing at R² = 0.990.
PythonXGBoostscikit-learnTensorFlow → repo
Reinforcement Learning Lunar Lander
deep RL
I built a Deep Q-Network agent from scratch in PyTorch to land a lunar module in OpenAI Gymnasium, no RL library shortcuts. That meant writing my own replay buffer, syncing a target network for stable learning, and tuning the reward balance until it consistently stuck the landing.
PythonPyTorchDeep Q-LearningGymnasium → repo
MNIST Generative Model
generative AI
I trained a Variational Autoencoder in PyTorch on the full MNIST dataset to generate new handwritten digits from random noise. Getting it to work meant using the reparameterization trick so gradients could flow through the sampling step, and balancing the loss so the model didn't just memorize pixels.
PythonPyTorchVAE → repo
Deutsch-Jozsa Algorithm
quantum
I implemented the Deutsch-Jozsa algorithm in Qiskit to show quantum speedup firsthand: classifying a hidden Boolean function in one query, versus many on a classical computer. I built the circuit for any number of qubits and validated it on IBM's noise-aware hardware simulator.
